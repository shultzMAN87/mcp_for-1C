# `FIX-18` — объект не находится по «Справочник.Имя»

Найдено датасетом `EVAL-1`. Ради такого он и заводился.

```powershell
docker compose build mcp-metadata-graph mcp-query-builder metadata-indexer workspace-watcher
docker compose up -d --no-deps --force-recreate mcp-metadata-graph
```

Переиндексация не нужна.

---

## Что не работало

Ваш же запрос показал причину:

```
eng = "Catalog.ЭдоОбщийУчастникиДО"
ru  = "Справочники.ЭдоОбщийУчастникиДО"
```

`full_name_ru` хранится во **множественном** числе вида. А в языке
запросов 1С пишут единственное — `Справочник.ЭдоОбщийУчастникиДО`, — и
именно так формулирует и человек, и агент.

Инструменты принимали только множественную форму, поэтому обращение к
объекту в самой естественной записи молча возвращало «не найдено». Не
ошибку — именно «не найдено», что гораздо хуже: агент делает вывод, что
такого объекта в конфигурации нет.

## Что исправлено

Везде, где идёт поиск по русскому имени, теперь принимается и форма
`<ВидЕдинственное>.<Имя>` — через сравнение с `kind_ru + '.' + name`.
Хранение не менялось, переиндексация не нужна.

**Мест оказалось пять, а не одно.** Я правил вручную то, что нашёл
грепом, и пропустил три. Все три вытащил контрактный тест, по одному за
прогон:

| Где | Что чинит |
|---|---|
| `metadata_object_attributes`, `metadata_referrers`, `metadata_object_details` | состав и ссылки объекта |
| `code_*` (поиск владельца) | код по русскому имени объекта |
| `metadata_subsystem_members` | состав подсистемы |
| `metadata_find_link_path` | путь связи между двумя объектами |
| `subsystem_scope` (`SCALE-1`) | границы подсистемы в поиске |

Последнее особенно неприятно: `subsystem="Подсистема.Продажи"` не
сработало бы, а `SCALE-1` в ответ честно сказал бы «в подсистеме ничего не
найдено, либо имя неверное» — и был бы формально прав, ничем при этом не
помогая.

## Новый тест

`TestRussianNameForms` в `tests_graph_contract.py`: везде, где в запросе
встречается `full_name_ru = $…`, рядом обязано быть сравнение с
единственной формой. Тест ищет по всем файлам серверов, поэтому пропустить
место, как я сейчас, больше не выйдет.

638 тестов, все проходят.
