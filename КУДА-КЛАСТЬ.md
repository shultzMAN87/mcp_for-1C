## B-1. Быстрый отказ для Neo4j

`make_guard()` держит вердикт «недоступна» тридцать секунд и всё это время
отвечает мгновенно, не трогая сеть. По истечении окна проба делается
заново — сервер поднимается сам.

Кешируется **только** «недоступна». `GRAPH_OK` не кешируется никогда:
сервер ослеп бы к падению Neo4j ровно на то же окно, а проба на живой базе
стоит миллисекунды. `GRAPH_EMPTY` тоже нет — кеш задержал бы момент, когда
индексация закончилась, это дефект `FIX-12` в чистом виде.

Кешированный отказ **называет себя кешированным**: в `detail` написано,
сколько секунд назад признана недоступной и когда следующая проверка. Урок
той приёмки, где `metadata_stats` молча отдавал картину здоровья.

Заодно закрыта ловушка из отчёта: `query-builder` пользовался своей копией
`_guard()` и правку общей точки не получил бы. Переведён на `make_guard`.

## B-2. Таймауты

Осторожнее, чем предлагалось в отчёте. Рабочие запросы оставлены на десяти
секундах: тяжёлые запросы к графу идут секундами (`metadata_stats` замерен
на 2,1 с), и резать им таймаут опасно — на большем графе или под нагрузкой
сломалось бы то, что работает.

Короткий таймаут (3 с) взяла только проба живости. Настраивается:
`NEO4J_HTTP_TIMEOUT_SEC`, `NEO4J_PROBE_TIMEOUT_SEC`, `GRAPH_RECHECK_SEC`.

## Замер B-1

Тот же, что делали для справки, — смотреть на время, а не на цвет:

```powershell
docker compose stop neo4j
python scripts\eval.py --dataset evals/datasets/metadata_graph.jsonl --no-deps
docker compose start neo4j
```

Было: восемнадцать примеров по **3 850 мс**, прогон около минуты.
Ожидается: первый ~3 000 мс, **все остальные — десятки миллисекунд**.
Все восемнадцать так же красные, это норма.

Дальше обязательно — восстановление:

```powershell
Start-Sleep -Seconds 40
python scripts\eval.py --dataset evals/datasets/metadata_graph.jsonl --no-deps
```

Должно вернуться **18/18 без перезапуска контейнера**. Если не вернулось —
сломано окно перепроверки, и это хуже исходной медленности: откачу `B-1`.

И заодно проверьте `query-builder` — он тоже должен стать быстрым:

```powershell

python scripts\eval.py --dataset evals/datasets/query_builder.jsonl --no-deps
```
