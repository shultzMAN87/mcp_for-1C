## Порядок

```powershell
# 1. Распаковать поверх корня
python scripts/run_all_tests.py     # ждём 891 тест в 27 наборах

# 2. Пересобрать bsl-checker
docker compose up -d --build --force-recreate mcp-bsl-checker

# 3. СВЕРКА — главное действие приёмки, без неё переключаться не стоит
docker exec mcp-bsl-checker python3 /app/bsl_lsp.py --compare .\workspace\CommonModules\АукОбщийКлиентСервер\Ext\Module.bsl

# 4. Датасет
python scripts/eval.py --dataset evals/datasets/bsl_checker.jsonl
```

Шаг 3 обязателен. Всё, что можно было проверить без java, покрыто тестами;
совпадение диагностик двух путей проверяется только на вашей машине. Если
сверка покажет расхождение — **не переключайтесь**, поставьте
`BSL_LSP_MODE=off` в `.env` и пришлите вывод.

## Откат

`BSL_LSP_MODE=off` в `.env` + перезапуск контейнера. Работает ровно то, что
работало вчера; быстрый путь даже не пытается стартовать.

## Что смотреть в датасете

`bsl-001`…`bsl-003` обязаны остаться зелёными — это и есть проверка, что
диагностики не изменились. Время должно упасть с ~10 с до долей секунды,
кроме первого примера: он платит за старт JVM.
