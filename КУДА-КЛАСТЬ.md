## Порядок

```powershell
# 1. Распаковать поверх корня проекта

# 2. Тесты на хосте — они от контейнеров не зависят
python scripts/run_all_tests.py          # ждём 833 теста в 25 наборах

# 3. Пересобрать образ bsl-checker (нужно только для B-7)
docker compose up -d --build --force-recreate mcp-bsl-checker

# 4. Датасет на живом стенде
python scripts/eval.py --dataset evals/datasets/bsl_checker.jsonl   # 9/9 hard
```

`--force-recreate` обязателен: `restart` не подхватывает новый образ.

В Cursor инструментов станет **37** вместо 36. Если `bsl_stats` не виден —
переподключите сервер в `.cursor/mcp.json`: список инструментов клиент
кеширует на сессию.

## Чего в архиве нет

Правок в `docker-compose.yml` и `.env.example` нет: три новые переменные
(`BSL_JAVA_CMD`, `BSL_ANALYSIS_TIMEOUT_SEC`, `BSL_PROBE_TIMEOUT_SEC`) имеют
умолчания и в штатной работе не нужны. Описаны в `README-B-7.md`.

`Dockerfile.python` изменился только удалением строки — пересобирать образы
метаданных и запросов ради этого не нужно, но при следующей сборке образ
станет на один файл легче.
