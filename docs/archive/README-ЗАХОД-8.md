## Порядок применения

### 1. Распаковать и прогнать тесты (30 секунд, без Docker)

```powershell
cd D:\Docker\30_mcp_cursor
python scripts\run_all_tests.py
```

Ожидается: `OK: проверено 43 наборов из 43, 1138 тестов`. Было 39 наборов
и 1051 тест.

Если какой-то набор красный — **дальше не идите**: правки трогают запись в
граф, и ошибка здесь дороже отката.

### 2. Пересобрать образы

```powershell
docker compose build mcp-metadata-graph metadata-indexer mcp-platform-help mcp-bsl-checker
docker compose up -d --force-recreate
```

⚠️ `docker compose restart` **не подхватывает новый образ** — нужен
`up -d --force-recreate`. На этом уже спотыкались при приёмке `SCALE-1`.

⚠️ Помните про цепочку зависимостей: перезапуск `mcp-metadata-graph`
тянет за собой `metadata-indexer`, а это ~14 минут сканирования. Флаг
`--no-deps` избавляет.

### 3. Посмотреть на граф прямо сейчас

В Cursor: **«покажи статистику графа»**. В ответе появился новый блок:

```json
"code": {
  "ownership": {
    "state": "ok",
    "callables": 231129,
    "without_owner": 28,
    "orphan_pct": 0.012,
    "answerable": true
  }
}
```

- `state: "ok"` — владение на месте, ничего делать не надо;
- `state: "broken"` — связь «модуль → метод» отсутствует. В ответе будет
  `answerable: false`, текст `meaning` (его читает агент) и `hint` с
  командой починки. Так выглядел граф 18 августа;
- `without_owner: 28` — известный штатный остаток: шесть модулей форм
  перечислений, которых нет в слое 1.

Заодно посмотрите `timing.neo4j_ms`. До первой полной индексации снимка
рёбер ещё нет, и число останется прежним (~1000 мс) — это ожидаемо, в
`index.relations` будет написано `"source": "подсчёт на лету"`.

## Что проверить на стенде

Полный список мер приёмки — в `ОТКРЫТОЕ.md`, первый раздел. Главные три:

### `FIX-27` — самолечение

Проверка занимает минуту и стоит того, потому что именно этот путь молчал
шесть дней:

```powershell
# 1. Ломаем владение руками (как это сделала бы прерванная фаза 2)
$OutputEncoding = New-Object System.Text.UTF8Encoding $false
[Console]::OutputEncoding = New-Object System.Text.UTF8Encoding $false
@'
MATCH (m:Module)-[r:HAS_METHOD]->() DELETE r;
'@ | docker exec -i neo4j cypher-shell -u neo4j -p <пароль>

# 2. Спрашиваем статистику в Cursor — ownership.state обязан стать broken

# 3. Запускаем индексер БЕЗ всяких форсов
docker compose up -d --force-recreate metadata-indexer
docker compose logs -f metadata-indexer
```

В логе обязано появиться:

```
Оба fingerprint совпали, но граф не в порядке:
  ⚠ владение кодом: процедур 231129, без владельца 231129 (100.0 %) ...
Отпечаток говорит про выгрузку, а не про граф. Запускаю фазу 2 —
она пересоберёт слой кода и связи владения; выгрузка при этом не
перечитывается.
```

**Раньше на этом месте было «данные актуальны, выход».** Фаза 2 займёт
около полутора часов (фикс-пойнт), фаза 1 не запускается — перечитывать
выгрузку незачем.

Если полтора часа сейчас не ко времени, проверку можно отложить: правка от
этого не станет менее нужной, но и вреда без проверки не будет — новый код
только добавляет проверки, ничего не удаляя.

### `FIX-28` / `FIX-29` — по логу ближайшего полного прогона

В сводке потерь строка про модули обязана стать `✓` либо `⚠` **с
названной причиной**:

```
модули → узлы :Module: вход 14679 → выход 14048, отсев 631
  причины отсева: общий модуль — узел слоя 1 уже есть ... 631
```

Ожидание: 631 = число общих модулей, дублей ноль. Если дубли есть — сторож
назовёт `module_id` поимённо, и это готовый адрес дефекта в выгрузке.

Рядом должна появиться строка про `HAS_METHOD`, если дубли пар есть:

```
рёбра HAS_METHOD:MetadataObject: строк 231102, из них дублей по паре 1 —
MERGE схлопнет их, в базе будет 231101 (напр. CommonModule.X.Проц)
```

### `SEARCH-1` — датасет справки

```powershell
python scripts\eval.py --dataset evals\datasets\platform_help.jsonl
```

Мера приёмки: `ph-030`…`ph-036` дают 7 из 7 soft, а `ph-001`…`ph-023` не
теряют **ни одного** пройденного предиката. Второе важнее первого.

Множитель настраивается без пересборки образа — в `.env`:

```
HELP_DIALECT_WEIGHT=1.5   # 1 — выключить правку целиком
```

Если соседи просели — начните с `1.2`, а не с подгонки под конкретный
пример.

## Что изменилось для агента

Три новых поля в ответах, всё остальное — по-прежнему:

- `code.ownership` в `metadata_stats` — с `answerable` и `meaning`;
- `usage` в `metadata_stats`, `platform_help_stats`, `bsl_stats` —
  счётчик вызовов за время жизни контейнера. Через неделю работы
  посмотрите `usage.never_called`: нули там — кандидаты на удаление из
  набора (`TOOL-1` для того и делался);
- `index.relations` в `metadata_stats` — откуда взялась табличка рёбер и
  насколько она свежая.

Ничего из существующих полей не переименовано и не удалено.
