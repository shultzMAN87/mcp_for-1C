## Проверка после распаковки

```powershell
python scripts\run_all_tests.py
```

⚠️ Именно `python`, не `python3`: в PowerShell `python3` перехватывает
заглушка Microsoft Store — печатает «Python», ничего не запускает и
возвращает нулевой код возврата. Если `python` не находится, `py -3`.

Если прогон где-то встанет, он теперь сам скажет где: имя идущего набора
видно в строке прогресса, а набор, не уложившийся в 300 секунд,
снимается с пометкой `ЗАВИС` (порог меняется через
`RUN_TESTS_TIMEOUT_SEC`).

Ожидается: **39 наборов, 1051 тест, зелено**, один набор не запускается
(`evals/runner/tests.py` — ему нужен пакет `mcp`, он гоняется в
контейнере).

Затем, если стенд поднят:

```powershell
docker compose build eval-runner
python scripts\eval_all.py
```

Семь новых примеров справки дадут hard-зелёное (там только `non_empty`), а
soft покажет, сколько промахов объясняются диалектом. **Это и есть
измерение** — красный soft здесь не регресс, а показание прибора.
