# Справка платформы 1С

`.hbk`-файлы сюда **не коммитятся**: это файлы 1С, распространять их
нельзя, и весят они за 40 МБ.

Скопируйте содержимое `C:\Program Files\1cv8\<версия>\bin\`. Критично
наличие:

| Файл | Размер | Что внутри |
|---|---|---|
| `shcntx_ru.hbk` | ~39 МБ | контекстная справка: методы, объекты, свойства |
| `shquery_ru.hbk` | ~0,2 МБ | язык запросов |
| `shclang_ru.hbk` | ~0,1 МБ | синтаксис языка |

Маленький размер последних двух — норма, а не признак заглушки. Полных
версий этих файлов не существует: проверено на 8.3.27 и 8.5.1.

Проверить, что всё на месте:

```
python scripts/check_prereqs.py
```

Индексация запускается сама при `docker compose up` и занимает около двух
часов (41 тысяча чанков, ~6/с на CPU). Прогресс виден в
`docker logs -f help-indexer`.
