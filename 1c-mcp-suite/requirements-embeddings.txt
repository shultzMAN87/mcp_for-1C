# ─── PERF-11. torch без CUDA ──────────────────────────────────────────
#
# Чистая пересборка 17 августа скачала ~2,5 ГБ колёс `nvidia-*` и `triton`.
# Их тянет `torch`: в сборке по умолчанию для linux/x86_64 CUDA-рантайм
# объявлен обязательной зависимостью, независимо от того, есть ли на машине
# GPU.
#
# На стенде GPU не проброшен. То есть в образе лежат два с половиной
# гигабайта, которые не выполняются ни разу, — та же болезнь, что у
# `pymupdf` (`DOC-2`), только весом в две тысячи раз больше. Цена: время
# сборки, размер образа, время выкачивания на каждой чистой машине.
#
# Лечится индексом CPU-сборок. Локальная версия `+cpu` по правилам PEP 440
# считается СТАРШЕ обычной `2.x.y`, поэтому при двух индексах побеждает она
# — отдельно закреплять версию не нужно.
#
# ⚠️ Строка ниже имеет смысл только через пересборку лока (`make lock`,
# на Windows — `.\scripts\gen_lockfiles.ps1`): она попадает в заголовок
# лок-файла, и уже оттуда её читает `pip install` при сборке образа.
# Правка этого файла БЕЗ пересборки лока не меняет ничего —
# `Dockerfile.embeddings` ставит по локу, а не отсюда.
#
# ─── HYG-6. Что этот индекс задевает кроме torch ────────────────────
#
# `--extra-index-url` — индекс ДОПОЛНИТЕЛЬНЫЙ, а не «индекс только для
# torch». Такого понятия у pip нет вовсе: указанный здесь адрес входит в
# множество источников для ВСЕГО файла, и любой пакет, который там
# найдётся, может приехать оттуда.
#
# Так и вышло. В логе чистой сборки 17 августа видно, что `jinja2` и
# `markupsafe` скачаны с `download.pytorch.org`, а не с PyPI. Версии те
# же и закреплены в локе, то есть поведение не изменилось — но решение
# принято молча, а молча принятые решения про цепочку поставки — это то,
# что потом объясняют задним числом.
#
# Оставлено осознанно: индекс официальный (зеркало PyPI, которое ведёт
# та же команда, что и torch), а сузить его до одного пакета можно только
# отдельным файлом ограничений — заметно сложнее ради двух пакетов,
# лежащих в локе с точными версиями и хешами.
#
# Проверить, что именно приехало не с PyPI, можно так:
#   grep -n "download.pytorch.org" requirements-embeddings.lock.txt
--extra-index-url https://download.pytorch.org/whl/cpu
